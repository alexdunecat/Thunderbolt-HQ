# Thunderbolt: Штаб ВВС Юктобании

Система для Foundry VTT v12 под Thunderbolt: An Aerial Knight RPG v1.3 с правилами нашего стола.

## Установка
Настройка → Системы → Установить систему → в поле «URL манифеста» вставить:
`https://raw.githubusercontent.com/alexdunecat/Thunderbolt-HQ/main/system.json`

Если сервер не достаёт до GitHub, запасной манифест через jsDelivr:
`https://cdn.jsdelivr.net/gh/alexdunecat/Thunderbolt-HQ@main/dist/system-jsdelivr.json`

Обновления приходят через кнопку «Обновить» там же.

## Что внутри
- **Пилот**: лист «Боевая карточка / Самолёт / Триггеры / Личное дело / Заметки». Клик по кубику у навыка — проверка d10 + навык против сложности (7 по умолчанию), d4 показывает Perk и Complication. На карточке броска кнопка «+1 Strain».
- **Самолёт** перетаскивается из компендиума «Ангар: самолёты» на лист. Машина одна: новая заменяет старую.
- **Спецоружие** и **триггеры** — из одноимённых компендиумов. Core-триггер добавляется сам при выборе архетипа.
- **Триггеры меняют чарник сами**: «Бронирование» +1 HP, «Стальное сердце» +3 Strain, «Безрассудство» +2 к выбранному навыку и т. д. Ситуативные («Опять ты!», «Отставить болтовню»…) включаются переключателем на боевой карточке, бонус попадает в броски отдельной строкой. Свои эффекты можно настроить на карточке триггера.
- **Бой**: Lock On!, Fox Two! (без броска или Improved), Guns, Break!, восстановление Strain, сваливание. Lock On! просит щёлкнуть по токену цели на сцене (Esc — отмена), захваченная цель дальше подставляется в Fox Two! и Guns; другую цель можно выбрать клавишей T. Урон наносит ведущий кнопкой на карточке атаки; при HP 0 спрашивается метка.
- **Трекер боя**: вместо броска инициативы заявка 1–3 действий. Кто заявил меньше, ходит раньше; при равенстве игрок раньше NPC. Новый раунд сбрасывает заявки и Break!.
- **Высота**: поле «Высота» на листе и высота токена связаны: 1 = Low, 2 = Medium, 3 = High.
- **Дальность**: одна клетка сетки = одна зона. Lock On! в своей и соседней зоне, захват срывается дальше двух зон; пушка только в своей зоне; у спецоружия своя дальность (поле «Дальность» на карточке). Запреты High/Low по высоте. Вне дальности лист спрашивает подтверждение.
- **Токены в зоне**: самолёты и цели в полклетки, в одной зоне помещаются четыре (в настройках мира можно 1/3 клетки, до девяти). Новый или передвинутый токен сам встаёт на свободное место своей зоны, с Shift остаётся где отпустили. Кнопка «Разложить токены» в панели AWACS приводит к этому размеру уже стоящие токены. Большие цели занимают несколько клеток (стратегические бомбардировщики 2×2, летающие крейсеры 6×2, подводные авианосцы 1×3) и стоят во всех своих зонах: дальность считается до ближайшей.
- **Залп конца раунда**: ракеты раунда долетают сами при смене раунда и при завершении боя; самая точная по цели плюс +1 или урон от остальных, защита с Break! и погодой; урон одной кнопкой ведущего.
- **Звено**: Perk и Complication передаются кнопкой с карточки (+1/−1 к следующей проверке себе или союзнику); Leadership добавляет ваш Lead к следующему броску союзников; «Вплотную» — строй с самолётами своей зоны, сам распадается при разлёте, «В строю» даёт соседям Lead к Evasion. Изменения чужих листов применяет ведущий через сокет системы.
- **Погода**: над всей сценой (панель AWACS) и по клеткам из импорта миссии; учитывается в защите, A-A/A-G, Push и порогах Complication.
- **Панель AWACS** (кнопка-антенна на панели токенов и в «Актёрах»): HP, Strain, Speed, защита, метки и захваты всех пилотов, цели на сцене, погода, «Все к вылету» и «Итоги вылета» (вылеты, сбитые, катапульта, очки навыков в личное дело).
- **NPC и цели**: 107 записей Штаба (самолёты, наземка, ПВО, флот, особые цели). Уровень (конскрипт, дуэлянт, ас) меняется на листе.
- **Памятка пилота**: журнал в компендиуме «Правила», оформлен в стиле Штаба и следует выбранному скину.
- **Импорт миссии**: раздел «Сцены» → «Импорт миссии AWACS» → вставить JSON из Планшета AWACS (кнопка «JSON»).
- **Оформление**: «Штаб», «ОС AC5», «Документация» — Настройки → Настроить параметры → система.

## Сборка данных
Цифры берутся из Штаба (`shtab/src/data.js`, `dossier.js`, `awacs.js`, `memo.html`):
```
npm install
npm run build
./tools/make-dist.sh   # архив dist/thunderbolt-shtab-<версия>.zip
```
